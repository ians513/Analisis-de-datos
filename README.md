# Analisis-de-datos
Proyecto realizado por Alessandro Lavezzi, Nicolas Opazo e Ian Spikin

Proyecto desarrollado para el curso de Análisis de Datos e Inferencia Estadística de la Universidad del Desarrollo. El objetivo es analizar la variabilidad hospitalaria en pacientes con cáncer de pulmón y tráquea en la Región Metropolitana, considerando severidad clínica, mortalidad, estadía hospitalaria y factores socioeconómicos.
